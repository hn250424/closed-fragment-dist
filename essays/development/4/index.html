Linux CAN

Linux에서 오픈 소스 CANAble 사용하기

2026년 3월 28일 19시 23분

1. 의존성 설치.

sudo apt-get update
sudo apt-get install can-utils

2. CANable USB 연결.

3. 연결 확인.

ls /dev/ttyACM*

4. idvendor, idproduct 확인.

lsusb

5. serial 확인.

sudo lsusb -d 16d0:117e -v | grep -i serial

6. .rules 파일 생성.

echo KERNEL=="ttyACM*",ATTRS{serial}=="207B30705330",MODE:="0777",SYMLINK+="can0" >> can0.rules
cat ./can0.rules

7. .rules 파일 이동.

sudo cp can0.rules /etc/udev/rules.d/

8. 적용.

sudo udevadm control --reload-rules

9. USB 재연결.

10. 인터페이스 생성 및 띄우기.

sudo slcand -o -c -s5 /dev/can0 can0
sudo ifconfig can0 up
ifconfig

11. 테스트.

터미널 A / sudo candump can0
터미널 B / sudo cansend can0 000#R
